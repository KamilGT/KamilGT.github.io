Expense Tracker

Веб-приложение для учёта доходов и расходов: операции с категориями, датами и комментариями, фильтрация и поиск, сводные показатели.

Кейс 03Веб-приложение

Expense Tracker

Доходы · Расходы · Категории

₽

Задача

Организовать учёт личных доходов и расходов так, чтобы операции было удобно вносить, находить и анализировать.

Реализованные функции

  • учёт доходов и расходов;
  • категории операций;
  • даты и комментарии к операциям;
  • фильтрация списка операций;
  • поиск по внесённым данным;
  • сводные показатели по доходам и расходам;
  • адаптивный интерфейс для мобильных устройств и десктопов.

Технологии

  • HTML5
  • CSS3
  • JavaScript (vanilla)
  • LocalStorage

Приложение реализовано без фреймворков и внешних библиотек: разметка, стили и логика написаны на HTML, CSS и JavaScript.

Особенности

  • данные сохраняются локально в браузере (localStorage) и не синхронизируются между устройствами;
  • очистка данных сайта в браузере удаляет сохранённые операции;
  • приложение работает как статическая страница без серверной части.

Публичная демонстрация и репозиторий проекта пока не опубликованы, поэтому в этом кейсе нет ссылок на работающую версию и исходный код. Описание составлено по известным характеристикам проекта; опубликованная версия приложения не проверялась.
